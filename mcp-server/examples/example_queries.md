## Tips for Effective Queries

### Be Specific
Instead of: "Tell me about meditation"
Try: "What are the different types of meditation practices taught in Buddhist and Hindu traditions?"

### Use Focus Areas Strategically
- Use `focus_area: "all"` for cross-domain insights
- Use specific focus areas when you want concentrated expertise in one domain

### Adjust top_k for Depth
- `top_k: 3-5` for quick, focused answers
- `top_k: 8-10` for comprehensive research
- `top_k: 15-20` for exhaustive curriculum development

### Ask Comparative Questions
Questions that compare traditions, steps, chakras, or concepts often yield rich insights.

### Request Practical Applications
Ask "how to" questions for practices, exercises, and techniques rather than just theoretical knowledge.

## Research Workflows

### Creating a Course Module
1. Start with a broad query (top_k: 15)
2. Follow up with specific focus area queries for each tradition
3. Ask for practical exercises and applications
4. Request integration across different approaches

### Understanding a Concept Deeply
1. Query the concept generally (focus: all)
2. Query it within each tradition (focus: mysticism, 12_steps, etc.)
3. Ask about practical applications
4. Explore related concepts and connections

### Finding Source Material
1. Use high top_k values (10-20)
2. Focus on specific teachers or texts
3. Note the metadata (teachers, traditions, source documents)
4. Follow up on specific sources mentioned
